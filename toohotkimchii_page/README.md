# 김남용 포트폴리오 (배달의민족 스타일)

인터넷활용 9주차 실습 **「AI를 활용한 홈페이지 제작」** 결과물입니다.
배달의민족 앱의 디자인 스타일(민트색 포인트, 둥근 카드, 큼직하고 귀여운 제목 글꼴)을 참고해 만든 개인 포트폴리오 홈페이지입니다.

- 🔗 사이트: https://toohotkimchii.github.io/kimnamyong_myhomepage/toohotkimchii_page/
- 🏠 기존 홈페이지: https://github.com/toohotkimchii/kimnamyong_myhomepage

---

## 1. 파일 구조

```
toohotkimchii_page/
├── index.html   # 구조 (header, nav, main, section, footer)
├── style.css    # 디자인 (민트 테마, 카드형 레이아웃, 반응형)
├── script.js    # 기능 (소개 문구 바꾸기, 필터, 검색, 좋아요, 연락 폼)
└── README.md    # 제작 과정 설명 (이 파일)
```

## 2. 페이지 구성

| 영역 | 내용 |
|---|---|
| Header | 로고, 메뉴(About / Portfolio / 제작 과정 / Contact), 검색창 |
| 메인 배너 | 인사말 + 버튼을 누르면 자기소개 문구가 바뀌는 기능 |
| 카테고리 | HTML / CSS / JavaScript / 준비중 아이콘 → 프로젝트 필터 |
| Portfolio | 프로젝트 카드 목록 (좋아요 버튼) |
| About Me | 학교, 학력, 기술 스택, GitHub |
| 제작 과정 | AI 활용 6단계 정리 |
| Contact | 이메일, 연락 폼 |
| Footer | 이름, 수업명, 연도 자동 표시 |

## 디자인 참고 포인트 (배달의민족 스타일)

- 메인 색상: 민트색(`#2ac1bc`) + 포인트 노란색
- 둥근 모서리의 흰색 카드, 연한 회색 배경
- 둥글고 큼직한 제목 글꼴(Jua)
- 상단 고정 헤더 + 둥근 검색창, 동그란 카테고리 아이콘

## 3. 제작 흐름 (수업의 추천 실습 흐름 적용)

1. **주제 정하기** – 배달의민족 스타일의 개인 포트폴리오
2. **시안 만들기** – 텍스트 프롬프트 방식 선택 (원하는 화면 구성과 스타일을 글로 설명)
3. **AI에게 요청** – HTML → CSS → JavaScript 순서로 나누어 요청
4. **실행 확인** – 브라우저에서 PC/모바일 화면 모두 확인
5. **직접 수정** – 색상, 문구, 여백, 기능 수정
6. **설명 정리** – 이 README에 프롬프트와 수정 내용 기록

## 4. 사용한 프롬프트

**1단계: 구조 요청**
```
대학생 포트폴리오 홈페이지의 HTML 구조를 만들어줘.
header, nav, main, section, footer 태그를 사용해줘.
메인 배너, 카테고리, 프로젝트(Portfolio), 자기소개(About), 제작 과정, 연락처(Contact) 영역을 넣어줘.
초보자가 이해할 수 있도록 주석을 달아줘.
```

**2단계: 디자인 요청**
```
위 HTML에 어울리는 CSS를 작성해줘.
배달의민족 앱 스타일처럼 민트색 포인트, 둥근 모서리, 카드형 레이아웃, 충분한 여백을 적용해줘.
제목은 둥글고 귀여운 글꼴, 본문은 읽기 쉬운 글꼴로 해줘.
모바일에서는 카드가 한 줄에 하나씩 보이게 해줘.
```

**3단계: 기능 요청**
```
버튼을 클릭하면 자기소개 문장이 바뀌는 JavaScript 기능을 추가해줘.
카테고리 버튼과 검색창으로 프로젝트 카드를 걸러내는 기능,
좋아요 버튼을 누르면 좋아요 개수가 올라가는 기능도 넣어줘.
querySelector 또는 getElementById를 사용하고 주석을 달아줘.
```

**수정 요청**
```
아래 코드에서 잘못된 부분을 찾아줘.
수정 이유를 설명하고, 수정된 전체 코드를 다시 보여줘.
특히 CSS 선택자와 JavaScript 이벤트 연결을 확인해줘.
```

## 5. 직접 검토·수정한 부분

- 기존 홈페이지에 있던 내 정보(학과, 학력, 이메일)로 내용을 바꿈
- 검색 결과가 없을 때 빈 화면 대신 안내 문구가 나오도록 추가
- 연락 폼에서 빈칸이면 오류 메시지를 빨간색으로 보여주도록 수정
- 자기소개 문구가 바뀔 때 박스 높이가 덜컹거려서 `min-height` 추가
- 모바일 화면에서 카테고리 아이콘이 넘치지 않도록 크기 조정
- 헤더를 `position: sticky`로 고정해 스크롤해도 메뉴가 보이게 함

## 6. 사용한 기술

- **HTML**: 시맨틱 태그(header, nav, main, section, article, footer), form
- **CSS**: CSS 변수(`:root`), Flexbox, Grid, `@media` 반응형, transition, `@keyframes` 애니메이션
- **JavaScript**: `getElementById`, `querySelectorAll`, `addEventListener`(click / input / submit), `classList`, `dataset`

## 7. 저작권·윤리 주의

- 배달의민족의 **로고, 이미지, 전용 글꼴(배민체), 문구는 사용하지 않았습니다.** 색감과 카드 배치 같은 디자인 스타일만 참고했습니다.
- 그림은 이미지 파일 대신 이모지와 CSS로 표현했습니다.
- 글꼴은 Google Fonts의 무료 글꼴(Jua, Noto Sans KR)을 사용했습니다.
- 연락 폼은 연습용이며 실제로 데이터를 전송하지 않습니다.
